# SQL-data-cleaning-project
## Project Overview
This project focuses on cleaning and transforming a raw dataset using SQL to prepare it for meaningful analysis. The dataset contained inconsistencies, missing values, duplicates, and formatting issues that needed to be addressed before insights could be generated.

The goal was to improve data quality and structure the dataset for reporting and business decision-making.

# Objectives
- Clean and standardize raw data for accurate analysis  
- Handle missing values and remove duplicates  
- Transform raw data into a structured format  
- Extract meaningful insights using SQL queries  

# Tools Used
- SQL (MySQL)

# Data Cleaning Process
- Removed duplicate records to ensure data integrity  
- Handled missing values using appropriate SQL techniques  
- Standardized inconsistent formats (dates, text fields, categories)  
- Filtered and cleaned irrelevant or incorrect data entries  
- Used CASE statements to create standardized categories  
- Applied JOIN operations to combine related datasets  
- Used GROUP BY, COUNT, SUM, and AVG for aggregation and summaries 

# Key SQL Techniques Used
- SELECT statements for data exploration  
- WHERE clause for filtering data  
- JOINs for combining tables  
- CASE statements for data transformation  
- Aggregate functions for summarizing data  
- CTEs (Common Table Expressions) for structured queries
  
# Key Outcomes
- Clean and structured dataset ready for analysis and visualization  
- Improved data consistency and accuracy  
- Strong foundation for building dashboards and reports  
- Demonstrated practical SQL skills for real-world data cleaning
